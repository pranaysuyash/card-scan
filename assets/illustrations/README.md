# Illustration Assets

This directory contains illustrations for empty states, onboarding, and error screens.

## Required Illustrations:

### Empty States:
- `empty_contacts.svg` - No contacts yet
- `empty_search.svg` - No search results
- `empty_batch.svg` - No batch scans

### Onboarding:
- `onboarding_1.svg` - Welcome screen
- `onboarding_2.svg` - Features overview
- `onboarding_3.svg` - Permission request
- `onboarding_4.svg` - First scan tutorial

### Error States:
- `error_camera.svg` - Camera permission denied
- `error_network.svg` - Network error
- `error_generic.svg` - General error

### Success States:
- `success_scan.svg` - Successful scan
- `success_export.svg` - Successful export
- `success_sync.svg` - Successful sync

## Illustration Style:
- Design: Minimal, modern, quantum-inspired
- Colors: Quantum theme palette
- Format: SVG for scalability
- Size: 200x200 to 400x400 viewport
