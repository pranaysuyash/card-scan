# Animation Assets

This directory contains Lottie animations for enhanced user experience.

## Required Animations:

- `scanning.json` - Scanning in progress animation
- `success.json` - Success celebration animation
- `loading.json` - General loading spinner
- `sync.json` - Cloud sync animation
- `processing.json` - Processing/thinking animation
- `empty_state.json` - Empty state animation

## Animation Specifications:
- Format: Lottie JSON (After Effects export)
- Duration: 1-3 seconds (loopable)
- Size: < 50KB per file
- Frame rate: 30fps
- Colors: Match quantum theme

## Tools:
- Create with Adobe After Effects + Bodymovin plugin
- Or use LottieFiles library (royalty-free)
