# Icon Assets

This directory contains application icons and visual assets.

## Required Icons:

- `app_icon.png` - Main app icon (1024x1024)
- `app_icon_foreground.png` - Android adaptive icon foreground (432x432)
- `splash_icon.png` - Splash screen icon (512x512)

## Social Media Icons (SVG preferred):
- `linkedin_icon.svg`
- `twitter_icon.svg`
- `facebook_icon.svg`
- `instagram_icon.svg`
- `github_icon.svg`
- `whatsapp_icon.svg`

## Feature Icons:
- `scan_icon.svg` - Scanning feature
- `batch_icon.svg` - Batch processing
- `qr_code_icon.svg` - QR code generation
- `export_icon.svg` - Export functionality
- `team_icon.svg` - Team collaboration
- `cloud_sync_icon.svg` - Cloud synchronization

## Icon Specifications:
- Format: PNG (raster), SVG (vector)
- Resolution: 1024x1024 for main icons, 24dp for feature icons
- Color: Quantum theme compatible (#00D9FF primary)
- Background: Transparent
